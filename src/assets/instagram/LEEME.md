# Fotos y vídeos de Instagram

Deja aquí los archivos descargados de https://www.instagram.com/clinicacorpomurcia/ con estos nombres
(extensión .jpg, .png, .webp, .mp4 o .webm). Si existen, las propuestas los usan automáticamente.

| Nombre          | Dónde aparece                                   |
|-----------------|-------------------------------------------------|
| hero-pilates    | Mitad de Pilates en la portada                  |
| hero-fisio      | Mitad de Fisioterapia en la portada             |
| pilates         | Sección de Pilates                              |
| pilates-1/2/3   | Fotos de los tres pasos de Pilates (Dúo)        |
| fisio           | Sección de Fisioterapia                         |
| fisio-manual / fisio-diatermia / fisio-ondas | Miniaturas de servicios de fisio (Dúo) |
| ecografia       | Tarjeta destacada de ecografía                  |
| clinica         | Imagen del espacio / recepción                  |

Para vídeo usa .mp4 (H.264) y que sea corto: se reproduce en bucle y sin sonido.
